Xshell、FinalShell、MobaXterm 的指纹记录与本助手不共享；需要在本机 Windows 的 SSH 记录里确认一次。

  1. 在你正在使用的 Windows 电脑按 Win + X，打开「终端」或「Windows PowerShell」。
  2. 复制下面的命令，粘贴到这个本机窗口后回车。命令按上方 SSH 地址和端口生成，不需要填写 PEM 路径。

  1. 出现 Are you sure you want to continue connecting 时，与服务器控制台提供的主机指纹核对；一致后输入 yes 再回车。
  2. 看到 Permanently added 表示记录已保存。随后即使提示 Permission denied (publickey) 也不影响这一步；若要求服务器密码，可按 Ctrl+C 结束，账号登录仍在网页完成；若进入服务器，输入 exit 返回。
  3. 回到本页，保留已选 PEM 文件，点击「检查连接与出口」，不用重启助手。

若提示主机密钥发生变化（REMOTE HOST IDENTIFICATION HAS CHANGED）或指纹不一致，请停止并核实服务器身份；这不是首次连接，不能照上面的步骤直接接受。若提示找不到 ssh 命令，请在 Windows「可选功能」中安装 OpenSSH 客户端。
